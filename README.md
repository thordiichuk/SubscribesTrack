# subtrack — особистий трекер і календар підписок

Односторінковий застосунок (SPA) для відстеження підписок і регулярних платежів: Netflix, Spotify, iCloud, інтернет, комуналка тощо.
Чистий HTML + CSS + vanilla JS, **без збірки й залежностей**. Деплой на GitHub Pages або Vercel за 1 хвилину.
Працює і як звичайний сайт, і як **міні-застосунок у Telegram** (Telegram Mini App).

## Можливості

- 🔐 **Захист PIN-кодом/паролем.** Коли PIN увімкнено, усі дані в `localStorage` **шифруються** (AES-GCM 256, ключ отримується з PIN через PBKDF2-SHA256 з 250 000 ітерацій). Саме ж PIN ніде не зберігається. Після 5 невдалих спроб вхід блокується на 30 с. Є автоблокування після бездіяльності. PIN можна змінити або вимкнути в налаштуваннях.
- 📋 **Підписки:** назва, посилання (сайт / скасування), ціна й валюта (zł, $, €, ₴, £, CHF, Kč), періодичність (щомісяця / щороку / щотижня / одноразово), дата наступного списання, категорія, примітка, статус (Активна, Пауза, До скасування, Скасована).
- 🔎 **Список:** пошук, фільтри за категоріями й статусом, сортування за датою, ціною та назвою.
- 📅 **Календар:** сітка на місяць з точками-індикаторами й сумами списань за день, деталі вибраного дня, гортання свайпом на телефоні. Повторювані платежі автоматично розгортаються на майбутні місяці.
- 📊 **Статистика:** сума на місяць і на рік (тижневі й річні платежі перераховуються в місячні, валюти конвертуються в основну), прогноз на 30 днів, смуга часток і таблиця за категоріями, найдорожчі підписки, економія від пауз і скасувань.
- ⚠️ **Нагадування:** підписки, до списання яких лишилося ≤1 дня, підсвічуються червоним, а ≤3 днів (або скільки вкажете в налаштуваннях) — жовтим. Також є банер угорі списку, push-сповіщення браузера та Telegram-бот.
- ✕ **Швидке скасування:** одна кнопка відкриває сайт сервісу й позначає підписку як скасовану (дію можна відмінити з тосту).
- 💾 **Резервні копії:** експорт і імпорт JSON (з вибором: замінити дані чи додати до наявних).
- 💱 Курси валют задаються вручну або оновлюються онлайн однією кнопкою (open.er-api.com, безкоштовно, без ключа).
- Мінімалістичний дизайн «паперовий реєстр»: світла тема за замовчуванням (темна — в налаштуваннях), один ніжно-блакитний акцент, моноширинні цифри (шрифти Onest і JetBrains Mono). Mobile-first, PWA: можна встановити на головний екран, працює офлайн.
- Дата наступного списання для повторюваних підписок сама переноситься вперед, коли минає.
- 📱 **Telegram Mini App:** відкривається з кнопки меню вашого бота, бере тему Telegram, має нативну кнопку «Назад», вібровідгук і діалоги Telegram, а дані синхронізуються між телефоном і ПК через хмарне сховище Telegram.

## Структура

```

```

## Деплой

### GitHub Pages
1. Запуште файли в репозиторій (гілка `master` або `main`).
2. Відкрийте **Settings → Pages → Build and deployment → Source: Deploy from a branch**, оберіть гілку та папку `/ (root)` і натисніть **Save**.
3. За хвилину застосунок з'явиться за адресою `https://<username>.github.io/<repo>/`.

### Vercel
1. На vercel.com натисніть **Add New → Project** та імпортуйте репозиторій.
2. Framework Preset: **Other**. Build Command і Output Directory залиште порожніми.
3. Натисніть **Deploy**.

### Локально
```bash
python3 -m http.server 8080
# відкрийте http://localhost:8080
```
> Шифрування (WebCrypto) і Service Worker працюють лише через HTTPS або на `localhost`. Якщо відкрити файл напряму (`file://`), вони не працюватимуть.

## Telegram Mini App

Окремий сервер не потрібен: бот лише відкриває вашу сторінку з GitHub Pages.

1. Задеплойте застосунок на GitHub Pages або Vercel (Telegram вимагає HTTPS).
2. У **@BotFather** надішліть `/newbot`, задайте ім'я та скопіюйте **Bot Token**.
3. Додайте кнопку відкриття застосунку:
   - `/mybots` → ваш бот → **Bot Settings → Menu Button → Configure menu button**;
   - надішліть URL застосунку, наприклад `https://thordiichuk.github.io/SubscribesTrack/`, і назву кнопки, наприклад `Підписки`.
   - *(Необов'язково)* `/newapp` створить пряме посилання виду `t.me/<бот>/<назва>`, яке відкриває застосунок одразу.
4. Відкрийте свого бота, натисніть **Start**, а потім кнопку меню зліва від поля вводу.
5. У застосунку відкрийте **Опції → Нагадування**, вставте токен бота й увімкніть Telegram. **Chat ID заповнюється автоматично.**

### Що змінюється всередині Telegram
| | Сайт у браузері | Mini App у Telegram |
|---|---|---|
| Де зберігаються дані | `localStorage` браузера | `localStorage` **+ хмарне сховище Telegram** (синхронізація між пристроями) |
| Тема | світла (або ваш вибір) | як у Telegram (або ваш вибір) |
| Підтвердження, посилання | системні | нативні вікна Telegram, посилання відкриваються в браузері |
| Резервна копія | завантаження файлу | файл приходить у чат з ботом (потрібен токен) |
| Сповіщення | браузер + Telegram-бот | Telegram-бот |

Дані в хмарі Telegram прив'язані до вашого акаунта й цього бота. Якщо увімкнено PIN, вони там **зашифровані**: на новому пристрої введіть той самий PIN.

**Перенести дані з сайту в Telegram:** на сайті натисніть «Завантажити копію (JSON)», потім у Mini App — «Відновити з JSON» і оберіть цей файл.

## Telegram-нагадування
1. У Telegram напишіть **@BotFather**, надішліть `/newbot` і скопіюйте **Bot Token**.
2. Надішліть своєму боту будь-яке повідомлення (інакше він не зможе вам писати).
3. Дізнайтеся свій **Chat ID** у **@userinfobot**.
4. У застосунку відкрийте **Налаштування → Нагадування**, увімкніть Telegram, вставте токен і Chat ID, потім натисніть «Надіслати тест». У Mini App Chat ID підставляється сам.

Нагадування надсилаються, коли застосунок відкрито: під час запуску, щогодини та під час повернення на вкладку. Сервера немає, тож коли застосунок закрито, бот сам не пише. Про кожне списання ви отримаєте одне повідомлення. Токен зберігається лише у вашому браузері (зашифрованим, якщо увімкнено PIN).

## Безпека й обмеження
- На сайті дані живуть **лише у браузері конкретного пристрою**. Щоб перенести їх, експортуйте JSON на одному пристрої та імпортуйте на іншому. У Telegram Mini App вони синхронізуються автоматично.
- Токен бота зберігається на клієнті (зашифрованим, якщо є PIN). Це прийнятно для особистого бота, але не публікуйте токен.
- **Забутий PIN відновити неможливо**, бо дані зашифровано ним. Робіть резервні копії: файл JSON не шифрується, тож зберігайте його в надійному місці.
- Сайт на GitHub Pages публічний, але в ньому немає ваших даних. Сторонні бачать лише порожній застосунок.
- Тег `noindex` не дає пошуковикам індексувати сторінку.
